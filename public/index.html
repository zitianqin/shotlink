Other clients (Codex, Cursor, Claude Desktop, Gemini…)

Same server everywhere — npx -y github:zitianqin/shotlink --token=… over stdio. Only Node 18+ is needed.

Cursor (~/.cursor/mcp.json) · Windsurf · Claude Desktop (claude_desktop_config.json) · Gemini CLI (~/.gemini/settings.json)

Then use it

  1. 1Restart Claude Code so it picks up the shotlink MCP server.
  2. 2Ask it to add a screenshot to a PR, or call upload_image(path="/abs/path/shot.png").
  3. 3It embeds the returned URL with gh — the image renders inline in the PR.

Security

Capability URLs. Uploaded links are public but unguessable — the same model GitHub's own user-attachments uses. Anyone with a link can view that image; nobody can guess it. Fine for UI screenshots; treat links to PII-bearing images as sensitive. Your token is personal and revocable. Uploads are image-only, max 50 MB.
