shotlink

Upload a local image, get a public link that renders inline in a GitHub PR. No browser, nothing committed to the repo. One command to set up.

Get your setup command

Paste this into your terminal:

This mints a personal token. Runs the shotlink MCP locally via npx — no clone, no config. Restart Claude Code after adding.

Then use it

  1. Restart Claude Code so it picks up the shotlink MCP server.
  2. Ask it to add a screenshot to a PR, or call the tool directly:
    upload_image(path="/abs/path/shot.png") → a public URL.
  3. It embeds the URL with gh; the image renders inline in the PR.

Security

Capability URLs. Uploaded links are public but unguessable — the same model GitHub's own user-attachments uses. Anyone with a link can view that image; nobody can guess it. Fine for UI screenshots; if an image holds PII, treat the link as sensitive. Your token is personal and revocable. Uploads are image-only, max 4 MB.
